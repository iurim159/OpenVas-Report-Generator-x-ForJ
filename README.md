# FORJ Vulnerability Assessment Report Generator

Tool autonomo in Python per convertire i report XML di OpenVAS / Greenbone in documenti Word (`.docx`) professionali, completi di grafici statistici, tabelle di inventario, analisi dettagliata e piano di remediation rigoroso (senza consigli generici o inventati).

---

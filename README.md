# FORJ Vulnerability Assessment Report Generator

Standalone Python tool to convert OpenVAS / Greenbone XML reports into professional Word documents (.docx), complete with statistical charts, inventory tables, detailed analysis, and a rigorous remediation plan (free of generic or fabricated advice).

---

## 🛠️ Requirements and installation

1. Make sure to have Python 3 installed on your system.
2. Install the requirements:
   ```bash
   pip install -r requirements.txt
3. run the tool:
   ```bash
   python3 VAxIP.py <file_report.xml>
